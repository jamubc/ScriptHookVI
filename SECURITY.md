# Security and responsible use

## What this software does to your machine

ScriptHookVI injects a DLL into another process and runs Lua scripts there with full read and write access to that process's memory. A script is a program. Run only scripts you have read or whose author you trust.

Antivirus products often flag DLL injectors. This project publishes no binaries: build from this repository's source. Builds from other sites are not ours.

## Responsible use

- Do not use this software with online or multiplayer software. Requests for online features, or for evading a copy protection, licence check or anti-cheat measure, are closed.
- The project provides no third-party software and will not help you obtain any.

## Reporting a vulnerability

Report privately through GitHub's "Report a vulnerability" button on the repository's Security tab. Do not open a public issue.
